# Домашнє завдання: Обчислення визначеного інтегралу

## Завдання:
1. Обчислити визначений інтеграл функції \(f(x) = x^2\) на відрізку [0, 2] за допомогою методу Монте-Карло.
2. Перевірити точність розрахунку, порівнявши результат з точним значенням та результатом, який дає метод `quad` з бібліотеки SciPy.

## Методи:
- Метод Монте-Карло використовує випадкові точки для оцінки площі під графіком функції.
- Функція `quad` з бібліотеки SciPy надає точне значення інтегралу.

## Результати:
- Результат інтеграції методом Монте-Карло: 2.6665
- Точний результат інтеграції: 2.6667
- Результат інтеграції методом `quad`: 2.6667, Похибка: $\(2.96 \times 10^{-11}\)$

## Висновки:
- Результат методу Монте-Карло дуже близький до точного значення інтегралу.
- Метод `quad` дає дуже точний результат, з похибкою близькою до нуля.
- Точність методу Монте-Карло залежить від кількості випадкових точок, і чим більше точок, тим точніший результат.
